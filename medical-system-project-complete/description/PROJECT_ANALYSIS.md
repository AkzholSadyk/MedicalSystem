# Medical System - Анализ проекта и требования

## Обзор проекта

Medical System - это веб-приложение для управления медицинской системой с тремя основными ролями пользователей:
- **Пациенты** - могут записываться на приём, просматривать свои медицинские записи
- **Врачи** - могут управлять расписанием, просматривать пациентов, создавать медицинские записи
- **Администраторы** - управление всей системой

## Технологический стек

### Backend
- **FastAPI** - современный Python фреймворк для API
- **SQLAlchemy** - ORM для работы с базой данных
- **SQLite/PostgreSQL** - база данных
- **JWT** - аутентификация и авторизация

### Frontend
- **Angular** - фреймворк для SPA
- **TypeScript** - типизированный JavaScript
- **Angular Material** - UI компоненты

### AI Chat Integration
- **OpenAI API** (доступен бесплатный API через переменную окружения)
- Модели: gpt-4.1-mini, gpt-4.1-nano, gemini-2.5-flash

### Существующие модели базы данных
1. **User** - пользователи системы (username, email, hashed_password)
2. **Patient** - пациенты (name, email, phone, date_of_birth)
3. **Doctor** - врачи (name, specialization, phone, email)
4. **Clinic** - клиники (name, address, phone)
5. **Department** - отделы (name, description, clinic_id)
6. **Appointment** - приёмы (appointment_date, time, status, patient_id, doctor_id)
7. **MedicalRecord** - медицинские записи (diagnosis, treatment, patient_id, doctor_id)

## Анализ Figma дизайна

### Интерфейс врача (Doctor Interface)
**Панель управления:**
- Статистика: Всего пациентов, Врачей, Записей на приём
- Медицинских записей, Клиник, Приёмов сегодня
- Ближайшие приёмы (с статусами: Завершён, Запланирован, Отменён)
- Последние медицинские записи

**Навигация:**
- Панель управления
- Пациенты (с поиском и возможностью добавления)
- Врачи
- Клиники
- Отделы
- Приёмы
- Мед. записи

**Управление пациентами:**
- Карточки пациентов с информацией: имя, возраст, телефон, email, адрес
- Кнопки редактирования и удаления

### Интерфейс пациента (Patient Interface)
**Личный кабинет:**
- Приветствие с именем пациента
- Статистика: Предстоящих приёмов, Завершённых приёмов, Медицинских записей, Всего приёмов
- Ближайшие приёмы
- Последние медицинские записи

**Навигация:**
- Главная
- Мои приёмы (история приёмов с деталями)
- Мои записи
- Врачи
- Записаться на приём

**Детали приёма:**
- Врач и специализация
- Дата и время
- Тип приёма (плановый осмотр)
- Статус (Завершён)

## Требуемые функции

### Основной функционал
1. **Аутентификация и авторизация**
   - Регистрация/вход для пациентов
   - Вход для врачей
   - JWT токены
   - Роли пользователей (patient, doctor, admin)

2. **Управление пациентами** (для врачей/админов)
   - Просмотр списка пациентов
   - Добавление нового пациента
   - Редактирование информации
   - Удаление пациента
   - Поиск по имени, email, телефону

3. **Управление врачами**
   - Список врачей
   - Информация о специализации
   - Контактные данные

4. **Управление приёмами**
   - Создание приёма
   - Просмотр приёмов (для пациента - свои, для врача - все)
   - Изменение статуса (Запланирован, Завершён, Отменён)
   - Календарь приёмов

5. **Медицинские записи**
   - Создание записи (только врач)
   - Просмотр записей (пациент - свои, врач - все)
   - Диагноз и лечение

6. **Клиники и отделы**
   - Управление клиниками
   - Управление отделами

7. **Панель управления (Dashboard)**
   - Статистика для врачей
   - Статистика для пациентов
   - Графики и метрики

### AI Chat функционал
1. **Интеграция AI чата**
   - Кнопка "AI Chat" в навигации
   - Чат-интерфейс для общения с AI
   - Использование OpenAI API (бесплатные модели)
   - Контекст медицинской системы
   - Помощь в анализе симптомов (предварительный анализ)

2. **Функции AI чата:**
   - Ответы на общие медицинские вопросы
   - Предварительный анализ симптомов
   - Рекомендации по записи к специалисту
   - История чата для каждого пользователя
